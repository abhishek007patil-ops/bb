The secret stays in memory for this tab and is never saved. Anything in a browser can be inspected, so keep this to local testing.

Setup

  1. Create an app at developer.spotify.com/dashboard with Web API enabled.
  2. Add the Redirect URI above to the app. Spotify only accepts https addresses or http://127.0.0.1, so open this page from a web address, not a downloaded file.
  3. Paste the Client ID here and log in.
